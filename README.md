# Al Dionaldo — Portfolio Website

A lightweight static portfolio built for GitHub Pages. No framework, paid hosting, or build step is required.

## Publish on GitHub Pages

1. Create a new GitHub repository (for example, `al-dionaldo-portfolio`).
2. Upload everything in this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the **main** branch and **/(root)** folder, then click **Save**.
6. GitHub will give you a public URL after deployment.
